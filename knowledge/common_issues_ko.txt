# 자주 발생하는 IT 문제 정리

## 1. 사내 Wi-Fi 접속 문제

- 현상
  - Wi-Fi SSID는 보이는데 접속이 안 됨
  - IP 충돌로 보이는 “Self-assigned IP” 상태
  - 인터넷은 되는데 내부 서비스(VPN, 인트라넷 등)만 안 됨

- 기본 점검 순서
  1. 다른 기기(휴대폰 등)에서는 동일한 Wi-Fi가 정상 동작하는지 확인
  2. 노트북에서 Wi-Fi 끄기/켜기, 해당 SSID '이 네트워크 삭제' 후 재접속
  3. IP 재할당: `네트워크 설정 → 고급 → DHCP 임대 갱신`
  4. 그래도 안 될 경우, IT팀에 다음 정보를 전달
     - 사용 중인 기기 종류(예: MacBook Air M2)
     - OS 버전, 위치(층/좌석), 대략적인 발생 시간

## 2. VPN 접속 오류

- 현상
  - VPN 연결이 아예 안 되거나, 자주 끊김
  - 사내 시스템(예: JIRA, Git, 사내 위키 등)에 접속이 안 됨

- 기본 점검 순서
  1. 사내/외부 네트워크에서 모두 같은 현상이 나는지 확인
  2. VPN 클라이언트를 완전히 종료 후 재실행
  3. 시간이 어긋나 있는지 확인 (시스템 시간 자동 동기화)
  4. 여전히 안 될 경우, IT팀에 다음 정보를 전달
     - VPN 클라이언트 종류 및 버전
     - 에러 메시지 전문(스크린샷 포함)
     - 접속 시도한 시간대

## 3. 계정 잠김 / 비밀번호 초기화

- 현상
  - 사내 계정 로그인 시도 후 여러 번 실패하여 계정이 잠김
  - “Too many failed attempts”, “Account locked” 메시지 등

- 기본 점검 순서
  1. Caps Lock, 한/영 전환 상태 확인
  2. 최근에 비밀번호를 변경했다면, 브라우저/앱에 저장된 이전 비밀번호가 자동으로 입력되고 있는지 확인
  3. 사내 비밀번호 정책(길이, 특수문자 포함 여부 등)에 맞는지 확인
  4. 계정이 이미 잠긴 경우, IT팀에 계정 ID와 발생 시간 전달 후 잠금 해제 요청

## 4. 노션 / 구글 독스 접근 문제

- 현상
  - 권한 없음(Unauthorized) 에러 표시
  - 사내 계정이 아닌 개인 계정으로 열려서 문서를 볼 수 없음

- 기본 점검 순서
  1. 브라우저 상단 프로필을 확인해 현재 로그인된 계정이 사내 계정인지 확인
  2. 사내 계정으로 다시 로그인 후 문서를 새로 열기
  3. 링크가 올바른 공유 설정(예: “도메인 내 모든 사용자 보기 가능”)으로 되어 있는지 문서 소유자에게 확인 요청

## 5. 슬랙 알림 미수신

- 현상
  - 채널/DM 메시지가 몰아서 오거나, 아예 알림이 오지 않음

- 기본 점검 순서
  1. 슬랙에서 `알림 일시중지(Do Not Disturb)`가 켜져 있는지 확인
  2. OS 알림 설정에서 Slack 알림이 허용되어 있는지 확인
  3. 모바일/데스크톱 중 어디에서 알림을 우선 받을지 설정 확인

## 6. PC(Windows) 현업 헬프데스크 주요 트러블슈팅

- **블루스크린(BSOD) 및 치명적 오류**
  - **DPC_WATCHDOG_VIOLATION**: 스토리지/네트워크 드라이버 충돌이 주원인. 최근 설치된 장치 드라이버 롤백, SATA AHCI 컨트롤러 업데이트로 해결.
  - **IRQL_NOT_LESS_OR_EQUAL**: 메모리나 드라이버 문제. `mdsched.exe`(Windows 메모리 진단) 실행 및 불량 RAM 교체 테스트.
  - **PAGE_FAULT_IN_NONPAGED_AREA**: 가상 메모리 페이징 오류. 페이징 파일 크기 자동 관리 설정 확인 혹은 디스크 검사(`chkdsk /f /r`).

- **네트워크 연결 및 VPN 통신 장애**
  - **인터넷 접속 불가 ("식별되지 않은 네트워크")**: 명령 프롬프트(CMD)를 관리자 권한으로 실행 후 `ipconfig /release`, `ipconfig /renew`, `ipconfig /flushdns`, `netsh winsock reset` 순차 입력 후 PC 재부팅.
  - **특정 사내망 접속 불가**: 프록시 설정 꼬임 확인. 제어판 > 인터넷 옵션 > 연결 > LAN 설정에서 '자동으로 설정 검색' 체크 여부 점검. VPN 클라이언트 재설치 필수.

- **소프트웨어 충돌 및 응답 없음**
  - 프로그램 멈춤 시, 작업 관리자(`Ctrl+Shift+Esc`)를 열고 응답 없는 프로세스에 우클릭 후 '작업 끝내기'.
  - **특정 앱 지속 충돌**: 이벤트 뷰어(Event Viewer)를 열고 `Windows 로그 -> 응용 프로그램`에서 에러 코드를 파악한 뒤 완전 삭제 후 재설치(AppData 폴더 찌꺼기 제거 포함).

- **PC 성능 저하 (부팅 및 실행 속도 극히 느림)**
  - **시작 프로그램 과다**: 작업 관리자의 '시작 프로그램' 탭에서 불필요한 서드파티 앱 "사용 안 함" 처리.
  - **C드라이브 용량 꽉 참**: 디스크 정리 기능 실행 또는 `Win+R` -> `%temp%` 폴더 파일 전체 삭제. 안티바이러스 전체 검사.

- **프린터 및 주변 장치 인식 불가**
  - **장치 관리자(devmgmt.msc) 노란색 느낌표**: 드라이버 완전 삭제 후 제조사 홈페이지 최신 드라이버 수동 설치.
  - **프린터 오프라인 / 인쇄 대기열 무한 대기**: 서비스(`services.msc`)에서 `Print Spooler` 서비스 중지 상태인지 확인. 중지 시크립트 후 `C:\Windows\System32\spool\PRINTERS` 폴더 내 파일 모두 삭제 후 Spooler 재시작.

## 7. Mac (macOS) 현업 헬프데스크 주요 트러블슈팅

- **커널 패닉(Kernel Panic) 및 강제 재부팅**
  - **증상**: 화면에 "컴퓨터를 재시동해야 합니다" 다국어 메시지가 뜨면서 Mac이 멈추거나 재부팅됨.
  - **해결**: 주로 타사 하드웨어(USB-C 허브, 듀얼 모니터 커넥터) 결함이나 서드파티 커널 확장 파일(Kext, 주로 구형 보안/백신 앱) 충돌. 주변 기기 전부 분리 후 부팅 확인.
  - **안전 모드 점검**: 부팅 시 Shift 키 유지(Intel) 혹은 전원 버튼 길게 누르기(Apple Silicon). 안전 모드에서 원인 앱 색출 후 삭제.

- **강제 종료 (바람개비 무한 로딩 / 앱 응답 없음)**
  - **기본 해결책**: `Option + Command + Esc` 단축키로 '응용 프로그램 강제 종료' 창을 호출하여 먹통된 앱 닫기.
  - **고급 해결책**: '활성 상태 보기(Activity Monitor)' 앱 실행 후, 붉은색으로 "응답 없음" 처리된 프로세스나 CPU/메모리 점유율을 독식하는 데몬을 수동 '강제 종료'.

- **시스템 하드웨어 초기화 (설정/전원 꼬임)**
  - **SMC 초기화 (전원/팬 오류)**: 배터리 관리, 키보드 백라이트, 팬 풀오작동 시 시행 (Intel Mac 전용. Apple Silicon은 재부팅 시 자동 점검).
  - **NVRAM/PRAM 초기화**: 해상도 꼬임, 소리 안 남, 시동 디스크 못 찾는 증상 시 부팅 중 `Option + Command + P + R`를 2회 부팅음 들릴 때까지 누름.

- **네트워크 (Wi-Fi) 연결 끊김 및 IP 충돌**
  - 시스템 설정 -> 네트워크 -> Wi-Fi -> '알려진 네트워크'에서 기록 전부 삭제 후 재연결이 가장 깔끔한 해결책.
  - 블루투스(Bluetooth) 간섭이 잦으므로 블루투스 비활성화 후 테스트.
  - '자체 할당된 IP' 문제 시 DHCP 갱신, 안 될 경우 새로운 '네트워크 위치' 프로필 생성 후 재적용.

- **저장 공간 "시스템 데이터/기타" 과다 차지 극복**
  - 디스크 공간 부족으로 성능 저하 시, 시스템 설정 > 일반 > 저장 공간에서 불필요한 iOS 백업 파일, 다운로드 항목 제거.
  - Finder에서 이동 -> 폴더로 이동(`Cmd+Shift+G`)하여 `~/Library/Caches`, `~/Library/Application Support` 내 거대 앱 캐시 수동 파기.

- **보안 권한 문제 (화면 공유/원격 지원 불가)**
  - 사내 IT 지원을 위해 TeamViewer, AnyDesk 등 원격 앱 실행 시 마우스 클릭이 안먹히거나 화면이 까만 경우 대응.
  - **해결**: 시스템 설정 -> 개인정보 보호 및 보안 -> **'화면 기록'** 및 **'손쉬운 사용(Accessibility)'** 항목에서 해당 원격 지원 앱의 토글을 반드시 활성화해주어야 함. (비밀번호/Touch ID 입력 필요)
